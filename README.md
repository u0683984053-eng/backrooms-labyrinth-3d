# 后室迷宫 3D（Backrooms Labyrinth 3D）

基于本地项目「后室迷宫（2D 原版）」的 **真 3D 化改造版**。原版项目零改动，本仓库为独立的新 3D 版本。

> 原版虽然使用 Three.js 渲染，但视觉上呈现"2.5D"效果：无纹理纯色材质、浓雾压低视野、无垂直维度（玩家 Y 轴固定）、装饰数据生成了却从未渲染。本 3D 版针对这些问题做了系统性升级，画面与玩法全面对齐 **Fandom（f 版）后室设定**：37 个具名层级、M.E.G. 档案体系、实体生态、补给物品与生存机制。

## 外部资产导入（腾讯混元 3D 等）

游戏支持**外部 AI 生成模型与真实纹理**替换程序化资产，放入文件即生效、缺失自动回退：

- **实体模型**：混元 3D / Tripo / Meshy 生成 GLB → 放入 `assets/models/{实体ID}.glb`（如 `smiler.glb`、`hound.glb`），自动缩放对齐（提示词与文件名对照见 `assets/ASSETS.md`）
- **真实纹理**：ambientCG / Poly Haven 下载 CC0 贴图 → 放入 `assets/textures/wallpaper.jpg`（carpet.jpg / ceiling.jpg / crate.jpg），自动平铺替换手绘纹理
- 服务器已支持 .glb/.webp MIME

## 最终验证（自动化 QA，无头 Edge + 帧缓冲）

- **37 个层级全量冒烟**：全部正常渲染，无 JS 错误（composer 后处理管线）
- **全系统回归**：跳跃 1.69m、冲刺动态 FOV 86°→78°、火盐抛物线命中 60 伤害、进度存档、M.E.G. 文档收集、通关结局
- **画面系统**：泛光后处理（UnrealBloomPass 半分辨率）、渐变天空穹顶、水面真实反射（Reflector）、粒子天气（雨/雪/气泡/尘埃）
- **性能**：原版 1394 draw calls → 个位数（InstancedMesh + 后处理管线）

## 亮度与渲染正确性

这一版修复了几个导致"画面太暗/发灰"的根因：

1. **纹理颜色空间**：所有 `CanvasTexture` 标记 `SRGBColorSpace`——此前纹理被当作线性数据读取，整幅画面被压暗约 2.2 伽马（墙纸 #c8b870 被渲染成暗棕）；
2. **光照模式**：切换 `useLegacyLights`——r160 默认物理光照下点光源强度（坎德拉）在 10 米外衰减到近乎为零，画面只剩环境光；legacy 模式下荧光灯点光源真正照亮墙面，产生明暗层次；
3. **出生视角**：出生时自动检测四方向、面朝最开阔的一侧，不再开局贴墙；
4. **雾色**：由纯黑改为暗暖色（#171410），远处墙体保持可见。

## 已知问题修复

- **天花板缺失**：洞穴（8）、木屋（27）、地狱（666）等封闭层级强制补齐天花板；户外层级不再悬浮荧光灯箱，改为白天光照；
- **画面闪烁**：闪烁逻辑从手电筒移到荧光灯本身（f 版设定：荧光灯嗡嗡作响、偶发闪烁），手电筒恒定亮度；
- **卡出墙（穿墙）**：原版碰撞对北墙的推挤方向错误（会把人拉过墙），且缺少"玩家确实在墙附近"的下界；已重写为**双向 AABB 推出**，并加入**子步进碰撞**（每步 ≤0.55m，高速冲刺 28m/s 不再穿透 0.3m 薄墙）+ **头顶碰撞**（平台下方起跳不会卡进平台内部）；
- **Level 0 封闭区域**：房间隔断交叉可能封死子区域 → 新增**迭代式 BFS 连通性修复**（所有格子保证从出生点可达，10 次随机生成验证 0 封闭格）；
- **层级设定对齐修正**：Level 27 木墙、Level 48 猩红森林红色树冠、Level 480 海滩沙地、Level 599 红色房间血红墙面、Level 10 丰收稻草人、Level 28 风暴石堡雷暴（闪电+雷声）。

## 验证

自动化验证（无头 Edge + 帧缓冲采样）：

- draw calls：1394 → 10~30（-98%）
- 跳跃物理：起跳后最高点 +1.69m（理论 ≈1.77m）
- 平台碰撞：从夹层上方落下精确停在台顶（4.55m = 2.85 + 1.7）
