# 后室迷宫 3D（Backrooms Labyrinth 3D）

基于 [后室迷宫（2D 原版）](https://github.com/u0683984053-eng/backrooms-labyrinth) 的 **真 3D 化改造版**。原版项目零改动，本仓库为独立的新 3D 版本。

> 原版虽然使用 Three.js 渲染，但视觉上呈现"2.5D"效果：无纹理纯色材质、浓雾压低视野、无垂直维度（玩家 Y 轴固定）、装饰数据生成了却从未渲染。本 3D 版针对这些问题做了系统性升级。

## 与原版的差异

| 维度 | 原版（2D 观感） | 3D 版 |
| --- | --- | --- |
| 墙 / 地板 / 天花板 | 纯色材质 | 程序化纹理：后室标志性泛黄墙纸（污渍/裂纹）、潮湿地毯、污渍天花板砖 |
| 墙体结构 | 单层盒子 | 主体墙 + 墙脚线 + 墙顶装饰线 |
| 灯光 | 稀疏点光源 + 浓雾（0.004） | 荧光灯发光面板 + 半球光 + 淡雾（0.0013），天花板灯区明显更亮，有真实光影层次 |
| 手电筒 | 仅聚光灯 | 聚光灯 + 半透明光锥 + 第一人称手电筒模型（含行走晃动） |
| 垂直维度 | 无（Y 固定，只能蹲下） | **重力 + 空格跳跃**（跳高 ≈1.7m）、可跳上木箱、Level 0 藏有一座**可攀爬的二层夹层**（三级阶梯 + 高台） |
| 装饰物 | 数据生成了但从未渲染 | 柱子、货架（带杂物）、管道（Level 2 管道之梦）、城市建筑窗带、树木全部实体渲染 |
| 实体 | 球/锥/圆柱 | 微笑者（笑脸纹理）、四足猎犬、飞蛾（半透明翅）、自爆者（发光核心）等组合模型 |
| 出口 | 地面方块 | 地面方块 + 发光光柱 |

## 运行方式

```bash
node server.js
# 打开 http://localhost:8080
```

或直接双击 `index.html`（需网络加载 three.js CDN）。

## 操作

- 鼠标 转视角 / 点击画面锁定鼠标
- `W A S D` 移动，`空格` 跳跃
- `Q` 冲刺（或双击 WASD），`C` 蹲下
- `F` 手电筒，`B / I` 背包，`` ` `` 层级传送（作弊面板）
- Level 0 深处有发光阶梯通向二层夹层

## 技术要点

- 纯原生 Three.js（r160，CDN 引入），无构建工具、无外部素材
- 全部纹理由 Canvas 2D 程序化生成（零资源文件）
- 跳跃/重力 + 平台 AABB 碰撞（可站在箱子、台阶、高台上）
- 层级系统、实体 AI、背包、理智值、音频全部保留自原版

## 文件结构

```
index.html          入口（3D 版）
server.js           静态服务器（8080）
js/
  renderer.js       3D 渲染器（纹理/灯光/平台/装饰/实体模型）
  player.js         玩家（重力、跳跃、平台碰撞）
  maze.js           迷宫生成（垂直维度：夹层/阶梯/箱子）
  config.js         层级配置（未改动）
  main.js           游戏主循环（仅透传 platforms 给玩家）
  entities.js       实体 AI（未改动）
  input.js          输入（未改动，天然支持空格）
  inventory.js      背包（未改动）
  audio.js          音频（未改动）
```

## 验证

自动化验证（无头 Edge + 帧缓冲采样）：

- 跳跃物理：起跳后最高点 +1.69m（理论 ≈1.77m）
- 平台碰撞：从夹层上方落下精确停在台顶（4.55m = 2.85 + 1.7）
- 渲染对比：画面暖色像素占比 9%（原版）→ 48%（3D 版），天花板灯区亮度为地板 2.5 倍
