# 后室迷宫 3D（Backrooms Labyrinth 3D）

基于本地项目「后室迷宫（2D 原版）」的 **真 3D 化改造版**。原版项目零改动，本仓库为独立的新 3D 版本。

> 原版虽然使用 Three.js 渲染，但视觉上呈现"2.5D"效果：无纹理纯色材质、浓雾压低视野、无垂直维度（玩家 Y 轴固定）、装饰数据生成了却从未渲染。本 3D 版针对这些问题做了系统性升级，并对画面、配色、空间结构按 [后室维基（Wikidot）](https://backrooms-zh-tr.wikidot.com/level-0) 的 Level 0 原设定做了对齐。

## 亮度与渲染正确性

这一版修复了几个导致"画面太暗/发灰"的根因：

1. **纹理颜色空间**：所有 `CanvasTexture` 标记 `SRGBColorSpace`——此前纹理被当作线性数据读取，整幅画面被压暗约 2.2 伽马（墙纸 #c8b870 被渲染成暗棕）；
2. **光照模式**：切换 `useLegacyLights`——r160 默认物理光照下点光源强度（坎德拉）在 10 米外衰减到近乎为零，画面只剩环境光；legacy 模式下荧光灯点光源真正照亮墙面，产生明暗层次；
3. **出生视角**：出生时自动检测四方向、面朝最开阔的一侧，不再开局贴墙；
4. **雾色**：由纯黑改为暗暖色（#171410），远处墙体保持可见。

## 性能

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| draw calls / 帧 | **1394** | **10~30（↓98%）** |
| 点光源数量 | 57 | 16 |
| 阴影贴图 | 1024² | 512² |

方法：所有同材质几何体（墙/踢脚线/顶线/地板/天花板/灯箱/建筑/树木/装饰）用 **InstancedMesh 实例化**（单位几何体 + 矩阵缩放）——900 格迷宫从 ~1400 次绘制调用降到 10 余次；灯光收敛为少量大范围点光源模拟荧光灯均匀照明。

## 运行方式

```bash
node server.js
# 打开 http://localhost:8080
```

或直接双击 `index.html`（需网络加载 three.js CDN）。

## 操作

- 鼠标 转视角 / 点击画面锁定鼠标
- `W A S D` 移动，`空格` 跳跃
- `Q` 冲刺（或双击 WASD），`C` 蹲下
- `F` 手电筒，`B / I` 背包，`` ` `` 层级传送（作弊面板）
- Level 0 深处有发光阶梯通向二层夹层

## 技术要点

- 纯原生 Three.js（r160，CDN 引入），无构建工具、无外部素材
- 全部纹理由 Canvas 2D 程序化生成（零资源文件）
- 跳跃/重力 + 平台 AABB 碰撞（可站在箱子、台阶、高台上）
- 层级系统、实体 AI、背包、理智值、音频全部保留自原版

## 文件结构

```
index.html          入口（3D 版）
server.js           静态服务器（8080）
js/
  renderer.js       3D 渲染器（InstancedMesh/纹理/灯光/多出口门/家具/实体模型）
  player.js         玩家（重力、跳跃、平台碰撞）
  maze.js           迷宫生成（大房间结构 + 多出口 + 家具 + 垂直维度）
  config.js         层级配置（未改动）
  main.js           游戏主循环（多出口检测、出生朝向、透传 platforms）
  entities.js       实体 AI（未改动）
  input.js          输入（未改动，天然支持空格）
  inventory.js      背包（未改动）
  audio.js          音频（荧光灯嗡声）
```

## 验证

自动化验证（无头 Edge + 帧缓冲采样）：

- draw calls：1394 → 10~30（-98%）
- 跳跃物理：起跳后最高点 +1.69m（理论 ≈1.77m）
- 平台碰撞：从夹层上方落下精确停在台顶（4.55m = 2.85 + 1.7）
- 亮度：修复前画面全屏均匀暗色（亮度范围仅 26 个灰阶）；修复后明亮且有层次（Level 0 平均 RGB (95,81,36)、灯区亮度为地毯 2 倍以上、Level 37 水面反光 84% 亮区）
- 多出口：每层 2~3 个出口（主出口 + 夹层隐藏出口）均可触发层级切换
